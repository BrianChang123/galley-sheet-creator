# SPEC: Gate 박스 고정·좌측 정렬 + 인쇄 좌측 잘림 수정

날짜: 2026-07-25

## 배경
- 2 Door open Gate는 inbound에만 미리 알 수 있고 그 외에는 승무원이
  수기로 작성한다. 현재 엑셀에서 gate 블록 높이가 MEAL 분량에 따라
  가변이라(남는 공간 흡수) 수기 작성 공간이 일정하지 않다.
- 제목 "★2 Door open Gate★"가 가운데(수직·수평 중앙, 15pt)에 있어
  수기 공간을 침범한다.
- 엑셀 export 후 인쇄 시 좌측이 잘려 좌측 테두리가 출력되지 않는다.
  (내용이 A열 0px 지점에서 시작 + 인쇄 가로 중앙 정렬로 양쪽 넘침)

## 요구사항
1. Gate 블록은 내용·MEAL 분량과 무관하게 **고정 크기**의 공백 박스로 유지
   (수기 작성 공간 일정). 입력값이 있으면 그대로 출력은 유지.
2. 제목은 좌측 상단 정렬, 폰트 12pt (미리보기도 동일하게 좌상단·12px).
   게이트 번호도 제목 아래 좌측 정렬.
3. 인쇄 좌측 잘림 수정:
   - 좌측에 폭 ~0.8자 스페이서 열을 두어 테두리가 용지 가장자리에
     붙지 않게 함 (내용은 B~E열).
   - 열 폭 합을 소폭 축소(34/13/13/44 → 32/12/12/42)해 A4 폭 내 여유 확보.
   - 인쇄 가로/세로 중앙 정렬 해제(왼쪽 여백 기준 고정).
