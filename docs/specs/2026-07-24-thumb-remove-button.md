# SPEC: 첨부 이미지 개별 제거(썸네일 hover × 버튼)

날짜: 2026-07-24

## 배경
이미지를 복수 첨부하면 전체 비우기("이미지 비우기")만 가능하고
특정 이미지 하나만 제거하는 방법이 없다.

## 요구사항
- 썸네일 위에 마우스 hover 시 이미지 우측 상단에 × 버튼이 나타난다.
- × 클릭 시 해당 이미지만 `uploadedImages`에서 제거되고 썸네일이 갱신된다.
- 마지막 이미지를 제거해 목록이 비면 file input과 AI 상태 문구도 초기화한다
  (기존 "이미지 비우기"와 동일한 상태).
- HEIC 플레이스홀더 썸네일에도 동일하게 동작한다.
